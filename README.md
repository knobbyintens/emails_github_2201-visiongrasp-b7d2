# VisionGrasp Neural Grasp Planner

## Repository Status

**🚧 To be released**

This repository will contain the implementation and experimental code for VisionGrasp Neural Grasp Planner, a neural grasp-planning model for cluttered bin picking. The code is still being prepared and is not yet available for public use.

## Overview

The project is being developed by the Arclight Robotics engineering team. A public release with the full implementation is planned after the camera-ready paper is finalised.

## Paper Information

- **Title**: VisionGrasp Neural Grasp Planner
- **Status**: Accepted at ICRA 2026 — camera-ready in preparation
- **Authors**: Arclight Robotics Research Team
